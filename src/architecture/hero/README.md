# 太和殿首轮独立构造资产

状态：`model`，未经G1–G7视觉/性能验收；不是最终完成资产。

## 接口与集成

`HeroPalace({ building: Building })` 只渲染 `taihedian`，保留传入的x/z/rotation。
在普通 `PalaceBuilding` 路由太和殿至此组件；同时停用旧太和殿台基、旧屋顶和旧台阶。

`taiheAssetSpec` 是纯数据 `HeroAssetSpec`，单位米，全部坐标为建筑局部坐标：

- `platformColliders`：三层退台盒。使用每层盒体；禁止再追加旧100×70×8.13实心盒。
- `bodyCollider`：内缩闭合殿身盒；外廊可行走，殿内仍不开放。
- `stairs`：x=-29/0/29三路、每路三段；`heroStairParts(flight)` 返回视觉用同一阶梯实体，以各Part的position及scale/2构建碰撞。
- 正面阶梯地面起点 z=41，最高终点 z=23；每层16级，每级0.169375米、踏面0.375米。
- `heroColumnGrid`：十一不等宽开间、五进深间；仅间数与公开包络有事实依据，具体分配是S3。
- `heroRoofGeometry`：独立上下檐、闭合有厚度屋面。材质组0为屋面，组1为厚边与下表面。

视觉构件合并为17个实例批次、2片屋面（各2个材质组）与2个内暗部盒，约23次主通道绘制，不含阴影通道。瓦件是几何实例，不只是颜色贴图。
`HeroPalace`和`buildHeroParts`接受可选`tileDetail: 'near' | 'mid' | 'none'`，默认`near`；中景瓦件数量低于近景40%，`none`关闭细瓦及瓦口端头，保留椽望。该选项只控制瓦件，不代表整座资产已完成各级LOD验收。
瓦陇前后坡固定世界X，端坡固定世界Z；按每条瓦陇与正脊/斜脊交点计算起点，再反算每个曲面点，不从正脊放射。
釉面统一使用父模块`materials.heroGlaze`，避免带瓦格照片与实体瓦陇叠加；内壳使用`materials.dark`。
局部节点保留 `userData.asset/status/accuracy/totalHeight` 以供检查。

## 石作近景截面与两档细分

`HeroStoneGeometry.ts`提供原创S3截面，`heroStoneGeometries('near' | 'mid')`返回归一化闭合几何；调用者在销毁后释放几何。
`HeroPalace`接受`stoneDetail: 'near' | 'mid'`，默认近景。两档采用相同包围盒和实例位置，不改变台阶或碰撞通行净宽。

- 80件柱础：盘足、颈部、鼓腹与上承面使用旋转截面，替换旧双层方盒；当前比例为S3，不称为测绘覆盆。
- 334组望柱：八角柱杆与中性层级柱帽分别实例化，无龙纹、莲花及其他未经校核浮雕。
- 334片栏板：边框、倒角、内收斜面和中央素板合成双面闭合实体；栏板内部面较边框内凹约4.2厘米（按0.14米板厚）。
- 668根上/下横枋继续共用方截面批次。本轮总计只增加柱帽、横枋两个实例批次。

上述柱础/望柱/栏板/横枋（不含台基与踏跺）的实例三角形约近景160,080、中景80,240；均为几何预算，不代表浏览器性能验收。
顶部雕刻、精确柱础曲线、石作纹样和所有原物形制仍需要参考校准。近景光照和接触阴影必须通过固定G3机位重新审查。

## 尺度与证据边界

控制包络宽63.96、深37、殿高26.92、台基8.13、总高35.05；上下檐比例不使用通用59%公式。
台基外围沿用原100×70。各层宽深、高度分配、线脚、栏杆节距、台阶具体配置、柱网宽度、柱高、屋面曲率、斗拱组件与门窗格芯均为美术重构。
所有近景构件目前由程序化基础实体构成，不冒充测绘或文物扫描。

## 尚未完成与生产风险

- 望柱头/栏板的经核实雕刻、须弥座精细曲线、螭首/排水、御路与阶侧石雕；盘形柱础、八角中性柱头和内凹栏板已有程序化截面，但不是文物雕刻交付。
- 鸱吻、仙人走兽、垂脊与戗脊的准确造型、数量和位置。当前脊端只保留中性结构块，不能称为复原神兽。
- 斗拱斗口制、昂翘曲线、转角科精确构造及逐构件彩画；目前为层级受力示意。
- 和玺彩画、门窗历史形制、贴金、精确纹样；没有添加未经核实的龙纹。
- 异形筒瓦/板瓦/勾头/滴水截面与重叠烘焙；当前只有贴合屋面的筒瓦分段、素面端头和连续基础坡面，不能称为雕刻瓦当交付。
- 木石边缘倒角、UV方向/密度、近景独立PBR、构件AO、许可记录和GLB源导出。
- 完整建筑LOD、空间分批裁剪、GPU性能和长时内存；已提供瓦件细节档位接口，距离切换和主体验收仍需集成实测。
- 三路台阶/台基/廊下的真实角色路线、12固定机位以及三种光照审核。测试通过不能替代这些审核。

视觉限制：门窗格芯后为闭合暗部，不代表已制作殿内。台阶为连续可行走重构，并非对文物所有栏杆开口的准确断言。
