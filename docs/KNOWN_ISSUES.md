# 已知问题与后续顺序

1. **视觉不是超写实成品。** 当前太和殿已做独立首轮构造、实体瓦陇和厚屋壳；灰泥与检验场石面已用有许可的实拍PBR，日光HDRI本地化。其他表面仍混用AI生成色图与解析微表面。缺准确雕刻、精确彩画、完整室内与全城同等细节。
2. **空间不是测绘成果。** 宫城外框采用公开总体尺度，OSM 与外框没有通过实地控制点做刚性校准。主体包络、特殊屋顶、台基、院墙和翼楼仍有近似，凹形轮廓分解约有一米栅格误差。
3. **仍有匿名与特殊建筑。** 588 个结构名称待核。比如延禧宫等特殊历史形态不能依靠统一屋顶生成器实现精确复原。
4. **部分高台仅能外部接近。** 已提供核心宫殿正面台阶；原始地图的未核石构筑物没有全部补充实测坡道。请沿主要门洞和已建台阶通行。
5. **临时角色与相机。** 行走是程序化摆动，暂无蒙皮人物或脚部IK。相机使用多条物理射线，复杂角落和视觉屋檐未具有完整相机形状扫掠，仍可能局部遮挡。
6. **外围水面为简化表示。** 不是流体或可游泳水体，宫城外不属于已验收步行区域；河道线形、护城河桥与外部景观尚待校准。
7. **流送规模有边界。** 已实现的是程序化细节配置流送，基础数据、低模和碰撞常驻。暂无真实GB级模型压缩、解码、显存峰值验收。
8. **性能目标未通过。** 参考 `PERFORMANCE.md` 的当前设备实测；不能将短时采样推断为长时间稳定60 FPS。核心物理WASM仍形成约2.2MB未压缩构建块。
9. **独立浏览器自动测试受环境限制。** 此环境Playwright启动浏览器报 `spawn UNKNOWN`，已使用连接浏览器的Playwright能力复验；标准脚本需要在允许启动浏览器的环境再跑。
10. **键盘与可访问性。** 主要按钮有名称、焦点样式和快捷键；弹窗尚未实现完整焦点圈定，移动端没有触屏角色控制，本版以桌面键鼠为目标。
