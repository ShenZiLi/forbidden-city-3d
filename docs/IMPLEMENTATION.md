# Forbidden City 3D · 实施记录

2026-10-19。工作区初始为空，Node 24.15.0 / npm 11.12.1。用户已授权按既定架构直接实施。

## 设计边界
采用 React 19 / R3F 9 / Rapier 2。统一米制世界，X 向东、Y 向上、-Z 向北。数据注册表同时驱动模型、碰撞、地图、交互与传送。程序化资产全部本地生成，不依赖外部模型服务。官方资料支持名称、宫城范围和部分形制；缺少测绘支持的数据一律为估计，不能称为数字孪生或超写实竣工版。

## 关键风险与处理
1. 缺少精细授权模型：实现可替换程序化资产，并公开精度限制。
2. 地图来源不是测绘：来源逐项保留，未知精度标记，不将误差预算当成测量精度。
3. 复杂场景耗时：远景低细节常驻，近区细节流送，固定碰撞不随视觉卸载。
4. Pointer Lock 依赖浏览器用户手势：入口按钮触发，Esc/失焦清空输入。
5. 性能受 GPU 与浏览器影响：报告实测环境，不预先宣称 60 FPS。
