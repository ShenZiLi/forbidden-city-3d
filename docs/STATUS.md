# 分阶段状态与区域清单

## 已有的可运行交付

- React19 / TypeScript / Vite / R3F9 / Drei10 / Rapier2 工程、本机服务、生产构建。
- 统一 WGS84 局部米制坐标及 841 个结构记录，包含 OSM way 追溯、footprint、包络、形制、来源、精度标记。
- 第一人称 Pointer Lock、第三人称临时角色、镜头避障、V 切换、WASD、奔跑、暂停、失焦重置。
- 固定步长的 Rapier KCC、胶囊、宫门开口、墙体、核心立柱、栏杆、阶台、基础园林障碍和分块地面。
- 曲面屋顶、单双檐、庑殿 / 歇山 / 攒尖等结构近似，柱网、斗拱、窗棂、阶台、实例化构件。
- 八区细节配置加载、取消、去重、错误重试、释放、远景保留，三档画质。
- 小地图、全图、建筑图鉴、十处安全传送、来源档案、设置、光照时段、合成声音。

## 各阶段结论

| 阶段 | 实际状态 | 尚未达到的部分 |
|---|---|---|
| 一：工程与基础世界 | 可运行并已浏览器检查 | 仍需更多浏览器与设备矩阵 |
| 二：空间灰盒 | 覆盖宫城主要区域和大量地图结构 | 没有取得完整测绘图，位置 / 高程未测绘校准 |
| 三：漫游与碰撞 | 核心控制、门洞、台阶及回归测试已实施 | 非全区域人工逐构件验收；相机使用多射线近似 |
| 四：写实建筑资产 | 模块化程序化结构可用 | 超写实扫描材质、高精 GLB、吻兽、和玺彩画、室内缺失 |
| 五：完整宫城扩建 | 东西宫殿、御花园及外围有广域轮廓 | 不是完整逐院落精细复原；588个结构名称待核 |
| 六：加载和优化 | 本地分区细节与共享生命周期可运行 | 大型压缩模型流送、长时间显存测试及45–60 FPS目标未验收 |
| 七：交互与验收 | 主要UI可用，浏览器交互有实测报告 | 独立Playwright进程启动失败；人工完整路线验收仍需补充 |
