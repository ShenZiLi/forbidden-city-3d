# 美术资源生产台账 · M0

更新日期：2026-10-20。长期目标仍是完整宫城的高完成度写实作品；本台账建立可追踪的生产任务与验收约束，**不表示全城、太和殿或任何构件包已精细复原**。

## 来源、证据和机器门禁

每项含优先级、等级、适用建筑/区域、状态、来源、证据文件、G0–G7及依赖。来源置信度沿用总方案：S0测绘，S1官方公开，S2地图/多视图推断，S3美术重构。**置信度是来源类别，不能代表当前资源已按该来源逐项校准。**

当前共同来源为本地总方案（S3、`brief-only`）：只支持生产范围与验收要求。涉及太和殿的记录附总方案引用的[官方概述](https://www.dpm.org.cn/explore/building/236465.html)（S1、`candidate`），仅支持已记录的建筑级事实；逐构件视图、引用页码、尺寸、年代与许可仍待整理。该来源不是瓦件、斗拱、彩画或雕刻的精确依据。参考照片未获得再分发许可时不能进入产品贴图。

`evidence`与各`gates.Gn.evidence`保存仓库内相对文件路径、类型与说明；24项原型已有实际文件证据，各门禁证据仍待审核。远程URL仅属于来源，不属于已交付文件。不得预填不存在的GLB、截图或性能报告。

| 门禁 | 必需证据类型 | 人工审查内容 |
|---|---|---|
| G0 | source | 尺寸、年代、来源与未知字段记录 |
| G1 | screenshot | 正侧顶形体、柱网与开间层次 |
| G2 | screenshot | 中性光下材质身份、通道、颜色空间与接缝 |
| G3 | screenshot | 六类近景，无漂浮、穿插、消失、塑料高光、拉伸 |
| G4 | screenshot | 院落、陈设、环境一体化，无明显灰盒 |
| G5 | route-test | 四条路线、视角与碰撞回归 |
| G6 | performance-report | 前台帧时、分区流送、10次往返和30分钟内存 |
| G7 | delivery-package | 可运行站点、源文件、许可、清单、影像及问题清单 |

调用 `validateArtAssetManifest(assets, { fileExists })` 返回带`assetId/code/gateId/message`的错误数组。`fileExists`由调用方提供，须针对仓库根目录检查实际文件；浏览器端未提供检查器时，任何声称存在的证据都会返回`unverified-evidence-file`。校验拒绝重复ID、缺来源、缺依赖、循环依赖、证据路径逃出仓库、文件缺失、实施却无实现证据，以及无完整门禁或依赖未验收的`accepted`。

所有`passed`门禁均需审核人、审核日期与相应文件类型。仅有测试报告无法通过G1–G4；只有文件名或文件存在仍不能证明图像质量，审核人必须实际阅读资料、查看截图和测量报告。机器校验不能识别伪造报告或判断画面是否写实。

## 固定审查机位

接口为 `src/art/reviewCameras.ts` 的 `reviewCameraPresets` 与 `getReviewCameraPreset(id)`。每项保存实际世界`position/target`、FOV、`time`、`quality`、`exposure`、版本、目的与`focusBuildingId`。坐标以当前建筑的`x/z/rotation`换算，不改变地图、碰撞与人物。

| ID | 用途 |
|---|---|
| taihe-front-eye | 正面人眼；距太和殿中心105米，世界眼高1.65米 |
| taihe-front-mid | 正面中景；独立抬高机位比较开间与上下檐 |
| taihe-45 | 东南45度全貌；局部偏移76/76米、世界高26米 |
| taihe-east / taihe-west | 东西侧面与坡面、端部检查 |
| taihe-rear | 背面；保留中和殿等真实邻近建筑的遮挡 |
| taihe-eaves | 檐下斗拱、梁底与受光 |
| taihe-column-base | 柱础、收分与木石接触 |
| taihe-door | 门窗厚度、格芯、裙板与暗部 |
| taihe-tile-edge | 瓦口截面、重叠和封檐厚度 |
| taihe-terrace | 三层退台、栏杆与台阶接触 |
| taihe-distant | 前院远景，距中心174米、眼高1.65米 |
| entrance-panorama | 午门南入口全景，眼高1.65米 |

这是太和殿12类与入口额外1类的M0机位组；其他A类建筑各自12机位仍在后续范围内。近景瞄准点依据现有工程体量安排，**不是测绘得到的构件坐标，也未证明已完成全部构件取景**。抬高或建筑内的审查摄影机不代表角色可站位置。新资产集成后应查看画面并版本化修订近景瞄准点，保留新旧机位信息。

当前默认morning/high/exposure=1作为可复现设置；柔和阴天、晴天斜光、正午三种光照对照仍由LIGHT01负责，不能把这一默认设置当作三种光照均通过。每轮保存1920×1080与近景图，同时记录资源版本、机位版本、曝光和画质；截图输出与人工审核尚待执行。
